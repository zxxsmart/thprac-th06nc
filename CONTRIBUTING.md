# Contributing to thprac-th06nc

This is an unofficial thprac fork. Report NC issues at
https://github.com/zxxsmart/thprac-th06nc/issues and include the fork version,
game version, language, selected stage/attack and steps to reproduce.

Do not attach game executables, extracted game archives, credentials or private
files. Replays need both the `.rpy` and `.rpy.thprac-nc` files.

Build with `build.ps1 -SingleFile`. Preserve the upstream game behavior and
replay metadata unless a deliberate compatibility change is documented.
Describe relevant tests and disclose AI assistance when submitting changes.

The upstream project's separate contribution policy, including its rule on
LLM-generated changes, is preserved in docs/upstream/CONTRIBUTING.md. This
fork's NC work must not be presented as an upstream-approved contribution or
competition-approved build.
